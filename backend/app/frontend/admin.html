Issue a membership code

For someone who paid for a membership in person: enter their name and a percent off, and a unique code is generated on the spot for you to hand them. Set a number of uses, or tick "Unlimited uses".

Generate monthly member codes (batch)

Bulk tool: creates one unique, single-use code for every member in the selected category, tagged to the chosen month. Re-running skips members who already have a code that month. Use this only if you track members by membership category; for one-off codes use "Issue a membership code" above.
